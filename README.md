# 🪨📄✂️ Stone, Paper & Scissors
A simple and fun Stone, Paper &amp; Scissors game built to practice JavaScript, game logic, and interactive UI.


# ⚙️ Technologies
- HTML
- CSS
- js(JavaScript)

# 🎮 What does it do?
- Play against the computer
- Automatically determines the winner
- Allows you to play again

# 📚 What I Learned
While building this project, I practiced:

- JavaScript
- Advanced css
- Conditional statements
- Random number generation
- DOM manipulation
- Event handling
- Making themes
